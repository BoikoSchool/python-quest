# Python Quest для планшетів

Вебтренажер Python для учнів 5–9 класів. Повне ТЗ: docs/SPEC.md (читай, коли починаєш новий етап).

## Стек і обмеження
- Чистий HTML/CSS/JS (ES-модулі), без фреймворків і без кроку збирання для сайту.
- Хостинг GitHub Pages: тільки відносні шляхи, жодних серверних заголовків.
- Python = Pyodide з vendor/pyodide/, виконується лише в js/py-worker.js.
- Жодних зовнішніх запитів у рантаймі: ні CDN, ні аналітики, ні шрифтів.
- Код учня не залишає пристрій. Персональних даних не збираємо.

## Мова
- Увесь текст інтерфейсу, повідомлення про помилки й місії — українською, простими словами.
- Коментарі в коді та коміти — українською.

## Команди
- Локальний сервер: npx serve .
- Тести: npx playwright test
- Перевірка місій: node tools/validate-missions.mjs
- Перезбирання CodeMirror: node tools/build-vendor.mjs
- PNG-іконки з icons/icon.svg: node tools/build-icons.mjs

## Правила роботи
- Перед кожним комітом: валідатор місій і Playwright мають бути зеленими.
- Нова залежність лише після мого погодження.
- Після кожного етапу зупинись і покажи, що змінилося.
