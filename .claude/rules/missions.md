# Місії
- Обов'язкові поля: id, title, topic, task, starter, tests, learn.
- learn — пояснення теми над завданням: title; text (2–5 речень простими словами); code — приклад на СХОЖІЙ, але іншій задачі, а не розв'язок місії; input, якщо приклад читає input(); lines — пояснення ключових рядків ({ code, text }, code — рядок із прикладу); indent — про відступи, обов'язково для умов, циклів і функцій.
- Приклад із learn має запускатися без помилок і НЕ проходити тести місії (це перевіряє валідатор).
- Мінімум 3 тести, з них хоча б один "hidden": true; обов'язково граничні випадки (0, від'ємні, порожній рядок).
- Еталонний розв'язок — у missions/solutions/<id>.py; на сторінку не завантажується.
- Тексти — для 10–15 років: до 2 речень у story, без жаргону.
- Після змін запусти node tools/validate-missions.mjs.
